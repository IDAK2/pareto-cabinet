# Slate reader

The reading view is cached for offline use and all primary controls are keyboard reachable with explicit accessible labels. Draft annotations remain only in memory and are lost when the browser closes.

## Constraint declaration

- OFFLINE: PASS — the reading view is cached for offline use.
- ACCESS: PASS — primary controls are keyboard reachable and explicitly labelled.
- RECOVERY: FAIL — annotations are lost when the browser closes.
